    New browser tab

    Opens a snapshot of the current page in a new tab of this browser, with its stylesheets, scripts, and images inline. It does not update as you edit, and links to other pages do not work.

    Live preview on this network

    Shares the open book read-only over HTTP, so a phone, tablet, or e-reader browser on the same Wi-Fi can download the .epub or read each chapter with the book's own styles. It serves only the files Export puts in the .epub, runs none of the book's scripts, and updates a moment after each edit. Anyone on your network who has the link can open it, so share it only on a network you trust. Sharing is off until you start it and stops when you press Stop or quit the app.

    A Kindle cannot open an .epub from its browser. Use Send to Kindle, or convert the book with Calibre and copy it over USB.

          Plainchant Scribe Guide

          Round-Trip Editing: Your Files Stay Yours

          Plainchant Scribe is an EPUB studio in development. New makes the files of an EPUB book and Load Example Book opens a short guide; the Stage shows the open chapter as a reading system parses it. Editing on the Stage, the Book panel, import, and export arrive in later phases, described in the manual; projects saved earlier still open as web pages. Your files are always the single source of truth: every visual action on the Stage splices only the exact character range it touches.

          • Select, Highlight & Edit Text in Place: In Design Mode, click any element on the Stage to highlight its code block in the Code editor and view its live margin/padding box model. Clicking a text element places a live text cursor right where you clicked so you can type and edit copy directly on the Stage while the HTML updates in real time.
          • Direct Stage Reordering: Drag elements on the Stage (or grab the ⠯ badge handle) to reorder them, or use the floating badge buttons (↑, ↓, ⧉, ✕) and Alt+↑/↓.
          • Dockable & Floating Inspector: Edit HTML attributes or use the CSS Designer to inspect computed styles, modify rules, or click Go to CSS ↗ to jump straight to the rule in your stylesheet. Toggle, collapse, or move the Inspector (bottom, top, left, right, or floating, from its Dock menu) (Ctrl/Cmd+Shift+I).
          • Right-Click Context Menu & Tab Shorthand: Right-click on the Stage or HTML editor for element actions, or type shorthand like section.hero or ul*3 and press Tab.
          • Multi-File Undo & Redo: Use Edit ▾ Undo / Redo or Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z (Ctrl+Y) across all files and visual actions.
          • Format: Edit ▾ Format file (Alt+Shift+F) re-indents and tidies the open HTML, CSS, or JS file in one undo step. HTML and CSS are rebuilt line by line; JavaScript is only re-indented.
          • Line Numbers & Find/Replace: The code editor shows line numbers. Press Ctrl/Cmd+F to find in the current file or Ctrl/Cmd+H to find and replace, or Ctrl/Cmd+Shift+F (the Project button) to search and replace in every file; Enter / Shift+Enter step through matches and Esc closes the bar.
          • Safe Folder Projects & Export: Opening a local folder creates an isolated Studio project environment. Changes are not written to local disk until you click Export, which preserves your existing folder and file structure.
