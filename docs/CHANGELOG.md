# Changelog

User-visible changes by release. Internal refactors and doc-only edits belong in git history and [HANDOFF.md](HANDOFF.md), not here.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/): `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`.

## [Unreleased]

### Added

- **EPUB 2 contents for older readers**: a Chapters tab switch adds `toc.ncx`, the table of contents EPUB 2 reading systems and some converters read, and keeps it in step with the contents as you edit and when you export. An NCX that came with an imported book is kept, checked in the Problems tab (including its links), and can be regenerated (`P7-04`, `D-049`).
- **Import Word documents**: Import text… in the Chapters tab now takes `.docx` files, and Open file… or a drop makes a new book from one, with its title and author. Each Heading 1 starts a chapter; bold, italic, small caps, links, footnotes and endnotes, lists, tables, images with their alt text and captions, block quotes, and scene breaks come across, and Word's fonts and spacing are left to the Layout tab (`P7-03`, `D-048`).
- **Contents page in the reading order**: a Chapters tab switch puts the contents page after the cover and front matter, as Amazon KDP asks, with the landmark Kindle's menu uses. Setting a cover now also writes the older cover tag Kobo reads (`D-047`).
- **Front and back matter**: Front and back matter… in the Chapters tab adds a title page, copyright page, dedication, epigraph, acknowledgements, about the author, or also by, each in its place in the book with the right type and role, and the title, author, publisher, ISBN, year, and rights filled in from the Book tab. The Problems tab says when one no longer matches the Book tab. Save a page to My library to add it to later books, filled with their own details. The Parts tab, which never applied to books, no longer shows in them (`P3-07`, `D-046`).
- **Page numbers, languages, roles, and alt text**: Page break… and Build page list add print page numbers and a page list, and the Book tab says where the numbers come from. Language… marks a passage in another language. Review alt text… lists every image to describe or mark decorative, and Add matching roles gives older chapters the ARIA roles screen readers need. New chapters, notes, and books carry those roles already. The Problems tab now also checks page lists, language tags, roles, unreachable chapters, contents out of order, and CSS that reorders text (`P6-02`, `D-045`).
- **Accessibility metadata**: the Book tab's new Accessibility section says how the book can be read (access modes, what is enough on its own, features, and flashing, motion, and sound hazards) and holds a summary, as EPUB Accessibility 1.1 requires. Suggest from the book fills in what Scribe can see, with its reasons, once you confirm. An optional conformance claim names who checked the book. The Problems tab warns when the metadata is missing or contradicts itself (`P6-01`, `D-044`).
- **Send to reader**: in the desktop app, File › Send to reader… shares the open book on your network. A phone, tablet, or e-reader browser can download the `.epub` or read each chapter with the book's own styles. A QR code carries the link to a phone, and the shared book updates a moment after each edit. Only the files the `.epub` holds are shared, and the book's scripts never run (`P5-07`, `D-043`).
- **EPUBCheck in the desktop app**: Run EPUBCheck in the Problems tab checks the book with your own EPUBCheck jar (chosen once; needs Java) and lists its messages in a new EPUBCheck category, each one jumping to the tag it is about. Nothing is downloaded, and the book is checked as Export would save it.
- **Book Problems tab**: for a book, the Problems tab now checks the whole book as EPUBCheck does: a new Package category (content.opf, the contents, file names, image formats, the cover, very long chapters), links and stylesheet `url()`s that point at missing, unlisted, or out-of-order files or at ids that do not exist, duplicate ids and mismatched languages, and accessibility warnings (missing alt text, skipped headings, links with no text). Each problem jumps to its text; export asks first if any are errors (`P5-04`, `D-040`).

- **Import Markdown and plain text**: Import text… in the Chapters tab turns `.md` and `.txt` files into chapters (a chapter per `#` heading), with footnotes as notes, images matched to the book's, and typeset quotes and dashes (`P5-03`, `D-039`).
- **Import .epub**: Open file… and drag-and-drop open an `.epub` as a new book, after checking the archive (unsafe names, sizes, damage, and zip bombs refuse it, with the reason); DRM-protected books are refused with an explanation (`P5-02`, `D-038`).
- **Export as .epub**: in a book, the Export dialog packs it into one `.epub` (mimetype first, text compressed, only the files content.opf lists), warns first if the book has errors, and updates its last-modified date; the desktop app asks where to save it (`P5-01`, `D-037`).
- **CSS lint**: in a book, the Problems panel's new Stylesheets category lists CSS that reading systems handle badly (fixed positioning, px font sizes, fixed text colours, grid and flex, and more) in stylesheets and style attributes, and the `direction` and `unicode-bidi` properties EPUB 3.3 forbids (`P4-06`, `D-036`).
- **Figures, tables, poems, and quotes**: the Layout tab inserts each after the paragraph selected on the Stage (a figure with alt text and a caption), and one switch keeps them readable on any screen; in a book, the Assets panel's Insert makes a figure (`P4-05`, `D-035`).
- **Footnotes and endnotes**: the Layout tab adds a numbered note to the paragraph selected on the Stage, as a footnote at the end of the chapter or an endnote in a Notes chapter, renumbers notes as they are added and removed, and can style the references (`P4-04`, `D-034`).
- **Embedded fonts**: the Layout tab imports TTF, OTF, WOFF, and WOFF2 fonts (reading their family, weight, and style, refusing fonts whose licence forbids embedding, and asking you to confirm the licence), and sets the body and heading fonts (`P4-03`, `D-033`).
- **Chapter openers, scene breaks, and small caps**: the Layout tab centres or lowers chapter titles, adds a drop cap or a small-caps first line, styles scene breaks as space or an ornament (with Insert scene break on the Stage), and offers a small caps class (`P4-02`, `D-032`).
- **Layout presets**: a Layout tab sets paragraph indents or spacing, line height, justification, hyphenation, and widows and orphans, from a Novel, Modern, or Plain start, written as one clearly marked block at the end of the book's stylesheet (`P4-01`, `D-031`).
- **Series and contributors**: the Book tab sets the series name and number (also written for Calibre), lists contributors such as editors and translators with roles and sort names, and moves creators and contributors up and down (`P3-06`, `D-030`).
- **Cover**: the Book tab chooses a cover image from the book's images or generates a typographic one (title and author in EB Garamond, three colour schemes), marks it as the cover, and keeps a cover page first in the book; Remove takes both away. Images added to a book now go into its own images folder (`P3-05`, `D-029`).
- **Generate contents**: on the Chapters tab, Generate contents… previews a table of contents built from the chapters' headings (one, two, or three levels) and the landmarks, then replaces the contents in one undo step, adding ids to headings that need them (`P3-04`, `D-028`).
- **Split and merge chapters**: select a heading on the Stage and Split at heading makes it the start of a new chapter; Merge joins a chapter with the next one. Links across the book and the table of contents follow, and undo reverses either in one step (`P3-03`, `D-027`).
- **Chapters organiser**: a Chapters tab in the Inspector adds a chapter after the one on the Stage, renames a chapter's title, deletes a chapter after asking, and moves chapters by drag or arrows. The table of contents follows each change, and undo reverses it in one step (`P3-02`, `D-026`).
- **Book panel**: a Book tab in the Inspector edits the title, language, date, publisher, rights, description, ISBN, and creators with roles and sort names, writing only the lines of `content.opf` they change. The identifier is shown read-only, and Update now stamps the modified date (`P3-01`, `D-025`).
- **Editing on the Stage for books**: click selects an element in a chapter, double-click edits its text, and dragging, the badge's buttons, the Inspector, and undo work as they do for web pages. Ctrl/Cmd+Click follows a link. An edit that would make a chapter invalid XHTML is refused with a notice (`P2-06`, `D-024`).
- **Moving through a book on the Stage**: « and » step between chapters, paging past the end of a chapter goes on to the next, Contents opens the table of contents over the Stage, and links between chapters work. Links that leave the book show their address instead of opening (`P2-05`, `D-023`).
- **Device presets for books**: Fit, Phone, E-ink 6", and Tablet on the Stage bar show the chapter at that screen's size, scaled to fit, with a rotate button for landscape; E-ink is greyscale with animation off (`P2-04`, `D-022`).
- **Paged and scroll layouts on the Stage**: paged (the default) splits the open chapter into pages the size of the Stage, like a reader, with ‹ Page n of m › on the Stage bar and the arrow and Page keys to turn them; Scroll in the Reader panel shows one continuous page (`P2-03`, `D-021`).
- **Reader settings on the Stage**: a Reader button sets text size, margins, and a light, sepia, or dark theme, the way a reading app does. They apply to every book, are remembered in this browser, and never change the book's files. The File menu's New is now New book (`P2-02`, `D-020`).
- **New makes an EPUB book**: the files of a reflowable EPUB 3 book (package document, contents, one chapter, a stylesheet), and **Load Example Book** opens a short three-chapter guide. The Stage shows the open chapter as a reading system parses it, with the book's own styles and images; a chapter that is not well-formed shows an error instead. Projects saved earlier still open as web pages (`P2-01`, `D-018`).
- **A manuscript look with light and dark modes**: warm paper and ink in light, lamplight in dark, with serif headings (EB Garamond) and typewriter code. Settings has Match system (the default), Light, and Dark; the old Retro theme is gone. The home page is rewritten to match and says plainly where the project stands (`P0-05`, `P0-06`, `D-008`).

### Fixed

- **Export keeps linked records.** A book whose package links a record inside it, such as the `onix.xml` in Standard Ebooks books, lost that file on export, and the Problems tab called it unlisted. Both are fixed (EPUB 3.3 §5.5.6).
- **Updates show on the next load.** The offline copy used to keep serving the old app after an update until the browser's site data was cleared; now the app is fetched fresh whenever the server can be reached, and the offline copy is used only when it cannot (`P0-07`, `D-019`).

### Removed

- Features the book tool will not use: the Live JS mode and Console, the Insert menu and drag-to-insert, the breakpoint switcher, flex and grid handles, and the pseudo-state bar. The Stage no longer runs scripts at all (`P0-04`).

### Changed

- **In-app dialogs for names and paths**: New file, New folder, renaming files, folders, and images, and Make shared part now ask in a Studio dialog that checks the name as you go, instead of the browser's prompt box.
- The studio is now Plainchant Scribe: new name, bundle id, version (`0.1.0`), and separate browser storage. The editing features are still those of the web-page editor it was copied from; book features arrive phase by phase ([ROADMAP.md](../ROADMAP.md)).
